# Учёт работников Университета «Синергия» (класс WORKER)

Кейс-задача № 3 учебной практики. Консольная программа на C# (.NET 8) хранит сведения
о работниках Университета «Синергия» и выводит фамилии тех, чей стаж в университете
превышает заданное число лет.

## Структура решения

| Путь | Назначение |
|---|---|
| `src/Synergy.Workers/` | **Отдельный модуль** (библиотека классов) с описанием классов и методов |
| `  Person.cs` | Базовый класс «Человек» (фамилия и инициалы) |
| `  Worker.cs` | Класс WORKER: должность, зарплата, год поступления, стаж |
| `  Teacher.cs` | Преподаватель: работник с кафедрой (пример наследования и полиморфизма) |
| `  WorkerConsole.cs` | Ввод с клавиатуры с проверкой и отбор работников по стажу |
| `  Validation.cs` | Общие проверки значений |
| `src/Synergy.Workers.App/Program.cs` | Консольная программа |
| `tests/Synergy.Workers.Tests/` | Модульные тесты xUnit (31 тест) |

## Сборка, запуск, тесты

Нужен [.NET SDK 8](https://dotnet.microsoft.com/download). Решение открывается в Visual Studio
(`SynergyWorkers.sln`) или из командной строки:

```bash
dotnet run --project src/Synergy.Workers.App
dotnet test
```

## Классы

```
Person
  - _fullName                          фамилия и инициалы
  + Person(), Person(fullName)
  + FullName { get; set; }             с проверкой на пустое значение
  + virtual Describe(), Display(), ToString()
      ▲
Worker : Person                        класс WORKER
  - _position, _salary, _hireYear
  + Worker()                                    конструктор по умолчанию
  + Worker(fullName, position)                  конструктор с параметрами
  + Worker(fullName, position, salary, year)    конструктор с параметрами
  + Worker(Worker other)                        конструктор копирования
  + ~Worker()                                   деструктор (финализатор)
  + Position, Salary, HireYear { get; set; }    изменение полей с проверкой
  + ChangePosition(position, salary)            перевод на другую должность
  + IndexSalary(percent)                        индексация зарплаты
  + GetExperience(year), HasExperienceOver(n, year)
  + override Describe()                         отображение полей
      ▲
Teacher : Worker
  + Department { get; set; }                    кафедра
  + override Describe()
```

`WorkerConsole.ReadWorker` читает одного работника с клавиатуры, `WorkerConsole.FindExperienced`
отбирает работников со стажем больше N лет. Объекты хранятся в `List<Worker>`.

### Правила

- Поля закрыты (`private`), доступ только через свойства и методы.
- ФИО, должность и кафедра не могут быть пустыми; зарплата не отрицательная;
  год поступления от 1950 до текущего. Нарушение вызывает исключение, объект не меняется.
- При вводе с клавиатуры неверное значение запрашивается повторно; зарплату можно вводить
  с запятой или точкой.
- Стаж = текущий год − год поступления (полных календарных лет), не меньше 0.
  «Превышает N» означает строго больше N.
- Деструктор в C# — финализатор, его вызывает сборщик мусора в неопределённый момент;
  в программе он только пишет запись в отладочный журнал.
